  <action>
Implement RoadNetworkLoader class with:

1. **load_roads_bbox(bbox: tuple[float, float, float, float]) -> GeoDataFrame**
   - bbox is (minx, miny, maxx, maxy) in the shapefile's CRS
   - Load only geometries intersecting bbox using GeoPandas bbox filter
   - Combine Trans_RoadSegment_0 and Trans_RoadSegment_1

2. **load_roads_radius(center: tuple[float, float], radius_meters: float) -> GeoDataFrame**
   - center is (lon, lat) in WGS84
   - Create circular buffer, transform to shapefile CRS, filter roads
   - Handle CRS transformation properly (shapefiles are likely in a projected CRS)

3. **load_roads_polygon(polygon: Polygon | GeoDataFrame) -> GeoDataFrame**
   - Generic method - accepts any polygon for clipping
   - County selection can use this with county boundary polygons
   - Use GeoPandas clip() for proper intersection

4. **Helper: _apply_buffer(gdf: GeoDataFrame, buffer_meters: float) -> GeoDataFrame**
   - Expand the selection area by buffer distance
   - Important: buffer in meters requires projected CRS, handle transformation

Key implementation notes:
- Use GeoPandas read_file() with bbox parameter for efficient bbox loading (reads only needed tiles)
- For point+radius, convert to bbox first for initial filter, then clip to actual circle
- Store the data directory path in constructor, default to "Road Data/NY/Shape/"
- Return GeoDataFrame with original CRS preserved
- Include 'geometry' and any useful attributes (road names, types if available)
